## 4. Issues found and fixed in this pass

| Issue | Fix |
|---|---|
| `aria-label` on a plain `<span>` (hero name) and `<div>` (tech marquee): `aria-prohibited-attr` | Name announced through an `sr-only` span; marquee gets `role="region"` |
| Contact form heading jumped from h1 to h3 | `h3` → `h2` |
| Resume tool categories jumped from h2 to h4 | `h4` → `h3` |
| Low-contrast footer, testimonial and skill-meter captions; active filter counter on /projects | Darker neutral shades in light mode, lighter in dark mode |
| Flowber cover lost `fetchpriority="high"` when it became a video | The still is rendered underneath as the LCP candidate; the loop covers it once playable |
| Oversized images (mascot 900 px, IG screenshots 1240 px shown at ≤ 420 px) | Resized to display size: mascot 360 px, IG 840 px, logos 300 px |
| `world-landscape.webp` (314 KB) shipped but never shown | Downsized to 108 KB and used as the case-study CTA background |
| AI clip `flowber-cover` shows a person walking into frame at ~2.2 s | Trimmed to 2.0 s and boomeranged into a seamless 4 s loop |
| Contact page still used the pre-Notion style and the old "BI/Data roles" pitch | Redesigned with the shared tokens, the author's photo, and the Data Engineer positioning |
| Portfolio project description out of date | Mentions react-pdf CVs, Remotion career film, and local AI media |

## 5. Known items, not fixed (by design or out of scope)

- **LCP 3.8–4.5 s on throttled mobile.** The site is a client-rendered SPA: text paints after the main bundle (≈129 KB gzip) and the route chunk. Real fix: prerender routes at build time (e.g. `vite-react-ssg`), which is a larger change than this pass. Desktop LCP is well under 2.5 s.
- **Flowber/Resume accessibility 96.** Remaining `color-contrast` hits are words of the scroll-driven `WordReveal` tagline (deliberately at 28% opacity until scrolled) and tags caught mid fade-in. Both reach full contrast in normal use.
- **"Danover at work" clip is soft.** It is the original phone footage; kept because it is real.
- **Projects page** still uses the earlier card style (blue/violet accents) rather than the Notion tokens. Functional and accessible; a candidate for the next visual pass.
